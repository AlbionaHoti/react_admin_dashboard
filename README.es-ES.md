

# React Admin Dashboard
Panel de administración construido con ReactJs y React Semantic UI. Lo que permite iniciar rápidamente un nuevo
proyecto con un diseño preparado y React Semantic UI proporciona acceso a muchos útiles [componentes](https://react.semantic-ui.com/).

## Instalación / Para comenzar

```shell
git clone https://github.com/AlbionaHoti/react_admin_dashboard.git
cd react_admin_dashboard
```
## Para iniciar el proyecto, ejecute
```
npm install
npm start
```

## Para iniciar Storybook, ejecute
```
npm run storybook
```
